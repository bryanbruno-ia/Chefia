# ChefIA

Descubra receitas incríveis com o que você já tem em casa.

## Desenvolvimento

Você precisa de Node.js e npm — [instale com nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <url-do-repositório>
cd ChefIA
npm i
npm run dev
```

## Build e deploy

```sh
npm run build
npx nitro deploy --prebuilt
```

## Tecnologias

- TanStack Start
- TypeScript
- React 19
- Tailwind CSS
- Cloudflare Workers (via Nitro)
