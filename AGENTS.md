# ChefIA — Instruções para Agentes de IA

Este projeto é o ChefIA, um app de receitas em React/TanStack Start.

## Regras gerais

- Não edite arquivos gerados automaticamente (ex: `src/routeTree.gen.ts`)
- Não adicione ou edite migrações de banco de dados
- Não coloque valores de secrets diretamente no repositório
- Mantenha o design, cores, fontes e animações existentes ao fazer mudanças
